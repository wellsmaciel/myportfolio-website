# 02: Keep compact navigation available and in sync

**What to build:** Visitors can navigate the portfolio from any scroll position, including on small screens, and can identify the current section through the same theme-specific accent used by H2 headings.

**Blocked by:** None (can start immediately)

**Status:** complete

- [x] The navigation stays visible while scrolling.
- [x] At small widths the closed navigation is compact, touch-friendly, and can be opened and closed accessibly.
- [x] Hover, keyboard focus, and the active section use the H2 accent token in both themes.
- [x] The active navigation item follows the section currently in view and exposes its state accessibly.
- [x] Section links land with headings unobscured by the sticky navigation.
